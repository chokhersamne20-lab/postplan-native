# PostPlan Native (Flutter)

ফেসবুক পোস্ট-শিডিউলারের নেটিভ অ্যান্ড্রয়েড অ্যাপ। স্পেসিফিকেশন: `../native-app-spec.md`

## 🚀 APK বানানোর পূর্ণ গাইড (প্রথমবার — ১৫ মিনিট)

### ধাপ ১: সার্ভার v17 ডিপ্লয় (এককালীন)
1. [script.google.com](https://script.google.com) → আপনার PostPlan প্রজেক্ট → **Code.gs** খুলুন
2. `postplan-code.gs`-এর **পুরো নতুন কোড** পেস্ট করুন (v17 — nget/nsave যোগ হয়েছে)
3. 💾 Save → **Deploy → Manage deployments → ✏️ → New version → Deploy**
4. (ক্লায়েন্ট HTML বদলায়নি — ওয়েব অ্যাপ আগের মতোই চলবে)

### ধাপ ২: গিটহাবে রিপো (এককালীন)
1. [github.com](https://github.com) → ডান-উপরে **+ → New repository**
2. নাম: `postplan-native` → **Public** (ফ্রি অ্যাকশনস) → Create
3. **"uploading an existing file"** লিংকে ক্লিক → `postplan_native` ফোল্ডারের **ভেতরের সব ফাইল/ফোল্ডার** টেনে ছাড়ুন
4. সবুজ **Commit changes** চাপুন

### ধাপ ৩: APK
1. রিপোতে **Actions** ট্যাব → চাইলে "I understand..." বাটন → **Build APK** → **Run workflow**
2. ৩-৬ মিনিটে সবুজ টিক → রানটা খুলে নিচে **Artifacts → postplan-release-apk** ডাউনলোড (zip)
3. zip খুলে `app-release.apk` ফোনে পাঠান → ইনস্টল (প্রথমবার "Unknown sources"-এর অনুমতি দিন)

### পরের বার আপডেট
ফাইলেই এডিট করে আবার Upload+Commit → নতুন APK নিজেই তৈরি। (ছোট বদলে পরে OTA আপডেটের ব্যবস্থা করা যাবে।)

## ফ্রি ক্লাউডে APK বানানো (প্রস্তাবিত — কম্পিউটারে কিছু লাগবে না)
1. এই ফোল্ডারটা GitHub-এ নতুন রিপো হিসেবে পুশ করুন (ফোল্ডারের ভেতরের সব ফাইল রিপোর রুটে)
2. GitHub → Actions ট্যাবে **"Build APK"** রান করুন
3. শেষ হলে Artifacts থেকে `postplan-release-apk` ডাউনলোড → ভেতরে `app-release.apk`
4. ফোনে পাঠিয়ে ইনস্টল করুন (প্রথমবার "Unknown sources" অনুমতি লাগবে)
